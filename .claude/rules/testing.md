# テストのルール

このファイルは、テストファイルを Claude が読み書きするときだけ読み込まれます。

- テスト名は「何をしたら、どうなるか」が分かる日本語または英語で書く（例: `未ログインなら /login にリダイレクトする`）。
- 1つのテストで確かめることは1つにする。
- 外部 API やデータベースはモックするか、テスト用の環境を使う。本番の接続先を使わない。
- テストを通すためだけに `.skip` を付けたり、期待値を実装に合わせて書き換えたりしない。仕様が変わった場合は、その理由をコミットメッセージか PR に書く。
- 不具合を直すときは、先にその不具合を再現するテストを書いてから直す。
